# Screeny 0.2.2

- You can now report a bug or suggest an improvement right from Screeny: "Report a bug…" and "Suggest an improvement…" are in the tray menu and in settings under **About**. No account needed.
- A bug report can include technical details: versions, display setup and the last lines of the error log with your user name taken out. You can see exactly what is sent, or turn it off. Screenshots are never attached.
- Reports are reviewed before anything is made public. If you prefer, the same window opens a GitHub issue instead.

# Screeny 0.2.2

- Об ошибке или идее теперь можно написать прямо из Screeny: «Сообщить об ошибке…» и «Предложить улучшение…» есть в меню трея и в настройках, в разделе **О программе**. Аккаунт не нужен.
- К сообщению об ошибке можно приложить технические подробности: версии, настройки экрана и последние строки журнала ошибок без имени пользователя. Перед отправкой видно, что именно уходит, и это можно выключить. Скриншоты не прикладываются никогда.
- Отчёты читаются, прежде чем что-либо станет публичным. Если удобнее, из того же окна можно открыть задачу на GitHub.

# Screeny 0.2.2

- Ahora puedes informar de un error o sugerir una mejora desde Screeny: «Informar de un error…» y «Sugerir una mejora…» están en el menú de la bandeja y en la configuración, en **Acerca de**. No hace falta cuenta.
- Un informe de error puede incluir datos técnicos: versiones, configuración de pantalla y las últimas líneas del registro de errores sin tu nombre de usuario. Puedes ver exactamente qué se envía o desactivarlo. Nunca se adjuntan capturas.
- Los informes se revisan antes de publicar nada. Si lo prefieres, la misma ventana abre una incidencia en GitHub.

# Screeny 0.2.2

- Screeny から直接、不具合の報告や改善の提案ができるようになりました。通知領域のメニューと、設定の **バージョン情報** に [不具合を報告…] と [改善を提案…] があります。アカウントは不要です。
- 不具合の報告には技術情報を添付できます: バージョン、ディスプレイ構成、ユーザー名を取り除いたエラーログの最後の数行です。送信内容は事前に確認でき、オフにもできます。スクリーンショットが添付されることはありません。
- レポートは公開前に必ず確認されます。GitHub で報告したい場合は、同じウィンドウから issue を開けます。
