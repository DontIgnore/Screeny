# Screeny 0.2.1

- Settings now end with an **About** section. It shows your version, and "Check for updates" checks right away, even with automatic checks turned off. When a new version is out, the "Update" button opens it.
- Links to what's new in your version, the license and the GitHub page are in the same place.
- The tray icon tooltip shows the version too.
- Russian interface wording is now consistent.

# Screeny 0.2.1

- La configuración termina ahora con la sección **Acerca de**: muestra qué versión tienes, y «Buscar actualizaciones» comprueba ahí mismo, aunque la búsqueda automática esté desactivada. Si hay una versión nueva, el botón «Actualizar» la abre.
