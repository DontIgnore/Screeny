# Screeny 0.2.3

- Screeny now runs on Microsoft .NET 10, which gets updates and security fixes until 2028.
- If your PC doesn't have .NET 10 yet, the installer and the update add it for you, and Windows may ask for permission. Nothing else changes.
- The portable version needs the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) installed first (free, from Microsoft).
