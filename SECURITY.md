# Security policy

## Reporting a vulnerability

Please report security problems privately, not as a public issue.

1. Open the [Security tab](https://github.com/DontIgnore/Screeny/security) of this repository.
2. Click "Report a vulnerability" and describe what you found.

That opens a private conversation between you and the maintainer. Include the Screeny version, what you did, and what
happened. If you can, say how serious you think it is. Please don't share details publicly until a fix is out.

Screeny is run by one person, so replies may take a few days. Every report gets read.

## Supported versions

Only the [latest release](https://github.com/DontIgnore/Screeny/releases/latest) gets fixes. Screeny updates itself, so
most people are on it already.
