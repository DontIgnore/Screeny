Screeny ONNX Runtime component — third-party components
========================================================

This archive contains no Screeny code. It holds the native ONNX Runtime that the
optional Screeny modules (precise OCR, semantic search) share, so that only one
copy is downloaded and loaded:

1. ONNX Runtime 1.31.0 (onnxruntime.dll, onnxruntime_providers_shared.dll)

   - Taken unmodified from the NuGet package Microsoft.ML.OnnxRuntime 1.31.0
     (runtimes/win-x64/native).
   - License: MIT, see onnxruntime-LICENSE.txt; third-party notices of ONNX Runtime
     are in onnxruntime-ThirdPartyNotices.txt.

2. Microsoft Visual C++ runtime (vcruntime140.dll, vcruntime140_1.dll,
   msvcp140.dll, msvcp140_1.dll)
   - Copyright (c) Microsoft Corporation.
   - onnxruntime.dll depends on these libraries. They are redistributable files of
     the Microsoft Visual C++ Redistributable (Visual Studio "Distributable Code",
     see Redist.txt of Visual Studio) and are shipped here unmodified for
     application-local use, so that the modules also work on systems without the
     Visual C++ Redistributable installed. Their use is subject to the Microsoft
     Software License Terms for Visual Studio and the Visual C++ Redistributable.
