Screeny precise OCR module — third-party components
====================================================

This archive contains no Screeny code. All pre- and post-processing lives in the
Screeny application (GPL-3.0). The module holds data only:

1. PP-OCRv5 models (det.onnx, rec.onnx)
   - det.onnx = ch_PP-OCRv5_det_mobile, rec.onnx = cyrillic_PP-OCRv5_rec_mobile
   - Original models: PaddleOCR, Copyright (c) PaddlePaddle Authors,
     https://github.com/PaddlePaddle/PaddleOCR
   - ONNX conversion: RapidOCR (RapidAI), ModelScope RapidAI/RapidOCR v3.10.0,
     https://www.modelscope.cn/models/RapidAI/RapidOCR
   - License: Apache License 2.0, see Apache-2.0.txt. The files are unmodified;
     only the file names were changed.

The native ONNX Runtime the module runs on is a separate download shared with
other Screeny modules (Screeny-OrtRuntime-N.zip, with its own notices).
